# LayerX 3D - Assets

Assets separados a partir do material visual criado para o wireframe.

## Estrutura
- `hero/` imagem principal da seção Hero
- `products/` imagens de referência dos produtos
- `brand/` logos/referências e tokens de cor
- `icons/` referência visual dos ícones de categorias

## Paleta
Azul: #087CF5
Preto: #0D0D0D
Branco: #FFFFFF
Fundo claro: #F4F5F7
Borda: #E5E7EB
Texto: #111111
Texto secundário: #666666

## Importante
As imagens de produtos são referências visuais geradas para o protótipo. Para a versão final da vitrine, substitua-as por fotos/renderizações reais dos produtos do seu amigo.
